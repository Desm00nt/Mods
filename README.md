# Mods

## Spraute Engine Lite 1.9.5 (Forge 1.20.1)

| Путь | Что это |
|---|---|
| `spraute_engine-lite-1.9.5-forge-1.20.1.jar` | исходный мод (не изменялся) |
| [`spraute_engine-src/`](spraute_engine-src/) | декомпилированные исходники — проект Forge, собирается `gradlew build` ([README](spraute_engine-src/README.md)) |
| [`docs/ANALYSIS.md`](docs/ANALYSIS.md) | как устроен мод, найденные ошибки и что исправлено, проверка исходников |
| [`docs/LANGUAGE_REFERENCE.md`](docs/LANGUAGE_REFERENCE.md) | справочник языка сюжетов `.sst`: все команды, функции, события, допустимые значения |
| `tools/decompile/` | конвейер декомпиляции: перевод имён SRG→Mojang, заглушки Minecraft/Forge, постобработка, `verify.sh` |
| `tools/analysis/` | проверки на запуске классов оригинала и пересобранного кода (сравнение поведения, сервер без клиента, цели миксинов) и генератор справочника |

Коротко о найденном (подробно — в `docs/ANALYSIS.md`, раздел 3):

1. Демо-проект «Пример» не загружался в мир: использовал несуществующую эмоцию `HAPPY_NEW` — **исправлено**.
2. В блочном редакторе Lite были видны 4 блока событий полной версии, которые давали ошибку — **исправлено**.
3. `/editor mcp on` в Lite молча ничего не делал — теперь сообщает, что это функция полной версии — **исправлено**.
4. Уязвимость: консоль редактора выполняла команды с наивысшим уровнем прав (4) для операторов уровня 2 — **исправлено**.
5. Мелкие недочёты (задержка событий `servertick`, утечка буферов передачи, и др.) — описаны с вариантами исправления.

Файлы `Hole_Digger_*.mcaddon` к Spraute Engine не относятся.
